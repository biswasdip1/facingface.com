# Newest Posts First

## What Changed

The normal FacingFace **Home Feed** now uses strict newest-first ordering. A newly published status, photo, video, audio post, document, poll, colour post, or reshare appears at the top of the Feed immediately after publishing.

The previous engagement ranking could allow an older post with more reactions or comments to appear above a newer post. That ranking has been removed from the main Home Feed so the publication time is always the primary order.

| Area | Ordering after this release |
| --- | --- |
| Normal Home Feed | Newest post first, using post time; identical timestamps use the newer post ID first. |
| Personal profile timeline | Existing newest-first order remains, with an intentionally pinned post still allowed at the top. |
| Page timeline | Unchanged. |
| Public Group timeline | Unchanged. |

## How to Check

Publish a normal post from the Home composer. After the “Post published” message, it should be the first post at the top of the Home Feed. Refreshing the page will keep the same newest-first ordering.

No Render environment, database, persistent disk, email, Start Command, Page privacy, Group privacy, or wall-post Public/Private setting needs to be changed.
